# AFTERCLASS — Student Community Hub

A self-contained static website. The main page is `index.html`.

## Deploy to Vercel (no command line required)
1. Create a new GitHub repository and upload `index.html`, `vercel.json`, and this README to the repository root.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Leave the framework preset as **Other**. No build command or output directory is needed for this static site.
5. Click **Deploy**. Vercel will provide a public URL after the deployment succeeds.

Note: event details/statistics are demo content and the registration form is front-end only; it does not save or send submissions.
